# Surface brief: site landing + marketing pages (NTC Training)

Scope: `site/` landing `/` and the marketing pages (`/tinh-nang`, `/template`, `/truong-hop-su-dung`, `/gioi-thieu`, `/ma-nguon-mo`). Mode: Persuade (docs/policies = Read, same world).
Audience: Vietnamese non-coder domain specialists and the engineers who install for them. Action: install (command + "Tải về & cài đặt").
Proof: the real editor (HTML, not a picture), the real MEM-001 error card copy, sourced numbers only. No testimonials/logos/stars.
Constraints: no trackers/CDN, OFL fonts self-hosted, NVIDIA only as factual lines; Cosmos is a candidate (no promotion).
User decision 2026-10-13: direction D4 "Chuẩn doanh nghiệp" (standing exit, category standard played straight) for site and dashboard.

## Direction contract
THESIS: The product is the hero. An enterprise-grade dark site where the working editor itself, wired and pre-checked, makes the claim "train a VLM without code, errors blocked before running". It refuses an illustrated hero, glow gradients and rows of icon cards.
OWN-WORLD: near-black neutral elevations with 1px hairlines; a single indigo accent #6e56cf for the primary action and selection; port families aqua ■ / blue ● / orange ◆ and status inks come only from design/tokens. Be Vietnam Pro for everything; JetBrains Mono only for commands and numbers; Lucide icons.
STORY: A visitor reads one plain-Vietnamese sentence, sees the editor wire itself and turn "✓ Sẵn sàng chạy", understands that mistakes are caught before a long training run, and copies the install command.
FIRST VIEWPORT: Top nav (wordmark NTC Training, 5 links, Tài liệu + primary "Tải về & cài đặt"). A two-line headline at left, ≤ 6rem. One supporting sentence. The install command block with copy, and the primary button on one row. Three factual chips (Apache-2.0, NeMo AutoModel, DGX Spark). Then the live editor frame starting inside the first viewport at ~60% of the width-plus.
FORM: canon (standing exit) chosen by the user over rolled direction D1 (index 3). Seed key 00ab95ce.
