# Regression subsets (ADR-002 B5, 500 questions x 6 benchmarks)

Generated by `uv run --no-project --with huggingface_hub --with pyarrow python -I scripts/qa/make_regression_subsets.py`
(bao-tester, 2026-10-12). Each JSON pins `repo@revision`, split, seed and the stratification; `samples[].row` is the row
index in that revision (harness order), `id` the dataset's own id when it has one, `q_sha256` a short question hash to
detect reordering. MMBench keeps circular variants together (500 questions -> 1865 rows) and must be scored circularly.
Regenerate only together with an ADR-002 note: changing a subset breaks paired comparisons with earlier runs.
