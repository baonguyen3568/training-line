# License check (models & datasets)

Background table and sources: `.team/knowledge/security.md` §6. I am not a lawyer — output is an engineering
risk classification; anything "conditional"/unclear for commercial use goes to PM → user.

## 0. Know the intended use
Ask PM if not yet decided (it changes everything): `research-internal` | `commercial-internal` | `redistribute-weights` | `serve-to-third-parties`.

## 1. Get the license from the PRIMARY source (not aggregators)
```bash
uvx --from huggingface_hub python -I -c "
from huggingface_hub import HfApi; import sys
api = HfApi(); rid, kind = sys.argv[1], sys.argv[2]
info = api.model_info(rid) if kind == 'model' else api.dataset_info(rid)
cd = info.card_data or {}
print('sha', info.sha, '| gated', getattr(info, 'gated', None))
print('license', cd.get('license'), cd.get('license_name'), cd.get('license_link'))
print('base_model', cd.get('base_model')); print('datasets', cd.get('datasets'))
print([s.rfilename for s in info.siblings if 'LICENSE' in s.rfilename.upper() or 'NOTICE' in s.rfilename.upper()])
" <org/repo> model|dataset
```
Then read the actual LICENSE file / license URL (WebFetch). The `license:` tag alone is not enough
(`other` / custom licenses are common: Gemma ToU, NVIDIA Open Model License, Llama Community License).

## 2. Follow the chain — a derivative inherits restrictions
- Fine-tuned model ← `base_model` license (e.g. InternVL weights ← LLM backbone license).
- Training data generated by another model (GPT-4/4V, Gemini, Claude captions) ← that provider's terms
  (e.g. LLaVA-Instruct = CC BY-NC 4.0 + OpenAI terms ⇒ non-commercial).
- Dataset of images ← image source licenses (COCO=Flickr per-image, LAION=URLs only, no rights granted).
- Older NVIDIA checkpoints may use non-commercial licenses (Internal Scientific R&D License) — check each card.

## 3. Classify
| Field | Values |
|---|---|
| commercial | yes / no / conditional |
| fine-tune & derivatives | yes / no / conditional |
| redistribute weights | yes / no / conditional (attribution, ToU pass-through) |
| obligations | attribution text, AUP/prohibited-use, MAU caps, naming ("Built with Llama"), share-alike |
| eval-only | yes for benchmarks (MMMU, MMBench, DocVQA, ChartQA, OCRBench, MathVista, AI2D, Video-MME…) |

Red flags ⇒ escalate: NC / ND / "research only", "no use to train other models", geographic restrictions,
license changed between revisions, missing license (= all rights reserved).

## 4. Record (required before the asset is used in any config)
`configs/security/licenses.yaml`:
```yaml
- repo_id: Qwen/Qwen3-VL-8B-Instruct
  kind: model            # model | dataset | benchmark | image | code
  revision: <sha>
  license: Apache-2.0    # SPDX id or exact name+version
  license_url: https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct/blob/<sha>/LICENSE
  upstream: []           # base_model / data-generating model chain
  commercial: yes
  derivatives: yes
  obligations: "keep LICENSE + NOTICE"
  eval_only: false
  reviewer: bao-security
  date: 2026-10-12
```

## 5. Report
SendMessage requester: `LICENSE <id>@<sha>: <license> — commercial=<..> derivatives=<..> — OK|ESCALATE (<why>)`
+ log line in `.team/log/YYYY-MM-DD.md`.
