## B. Node mới — điều kiện bảo mật (đưa thẳng vào thiết kế)

1. **Dữ liệu tải từ ngoài (HF dataset / URL)**
   - Chỉ HF Hub (repo + revision SHA pin; UI chọn `main` thì host resolve ra SHA và ghi vào run.json). URL tuỳ ý: không làm cho 1.0.
   - Không bao giờ `trust_remote_code` cho dataset; repo có loading script `*.py` → lỗi validate dễ hiểu ("dataset cần chạy code, chưa hỗ trợ").
   - Chỉ nhận parquet/arrow/jsonl/webdataset tar + ảnh PNG/JPEG/WEBP; mọi ảnh qua `common.image_rules.open_image` (allowlist format, 40 MP, bomb = lỗi).
   - Tar: không theo symlink/hardlink, không path tuyệt đối/`..`, giới hạn tổng byte giải nén + số file (`tarfile` filter=`data`).
   - Download chạy trong job riêng: rw đúng 1 thư mục đích; token HF read-only qua compose secret, không vào env của job train; job tải có network, job xử lý tiếp theo `--network none`.
   - License dataset: field bắt buộc trong node output (đi theo P012 export notices); `unknown` → cảnh báo vàng + chặn "xuất/chia sẻ".
2. **DPO/GRPO reward code**
   - 1.0 chỉ cho **reward dựng sẵn** (exact match, regex/format, IoU, số học, JSON schema) chọn bằng tham số. **Không** cho user dán Python tuỳ ý (đó là code execution: cần sandbox riêng, chưa có).
   - Regex do user nhập: giới hạn độ dài + timeout (ReDoS) hoặc dùng `re2` nếu có wheel arm64.
   - Reward model (LLM-as-judge) = model như mọi model khác: phải có trong catalog, đã vet.
   - Nếu sau này mở "custom reward": proposal riêng + container `--network none`, read-only, không secret, CPU/time limit.
3. **Caption bằng VLM**
   - Model caption phải nằm trong catalog (đã vet). Output caption là **text không tin cậy**: hiện trong UI qua React (escape), không render HTML/Markdown thô; giới hạn độ dài.
   - Prompt injection từ ảnh không gây hại hệ thống vì caption chỉ là dữ liệu, nhưng ghi rõ cảnh báo chất lượng trong docs.
   - Chạy như job GPU bình thường (lock, memguard, mount thu hẹp bước 6).
4. **Mọi node mới**: qua `check_support`, job container dùng `ro_inputs` (P017 bước 6), không mount project, không secret ngoài allowlist, image đã APPROVED trong IMAGES.lock (require_approved_image mặc định True).

## A. Đóng gói — điều kiện review (tóm tắt từ P015/P017, đối chiếu khi PR tới)

- vlm-runner sidecar: socket unix typed API; app KHÔNG có docker.sock; runner không nhận flag docker tự do.
- Compose: mọi port bind `127.0.0.1`; secrets qua `secrets:` (file), không `environment:`; không mount repo root vào app/runner; app/site non-root, `read_only: true` + tmpfs khi được; `cap_drop: [ALL]`, `no-new-privileges`.
- Build: `.dockerignore` loại `.env*`, `outputs/`, `data/`, `.cache/`, `.git/`; kiểm bằng `scripts/security/dump_build_context.sh` (canary .env không xuất hiện). Base image pin digest trong IMAGES.lock, cả amd64 + arm64 digest.
- Multi-arch: digest từng arch ghi riêng; amd64 build-only = ghi "chưa test GPU" (không claim).
- Settings DB D-7: AES-GCM, write-only, last4, audit jsonl; policy admin chỉ đọc từ `~/.config/ntc-training/policy.toml`.
- Mount thu hẹp (P017 bước 6) phải merge trước release.
