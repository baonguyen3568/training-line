Hiện chỉ có cách cài **từ mã nguồn**. Xem [Yêu cầu hệ thống](/docs/yeu-cau-he-thong/) trước.

## 1. Lấy mã nguồn và cài Python

Địa chỉ kho mã: `{{TODO_USER: địa chỉ kho mã công khai}}`

```bash
git clone <địa chỉ kho mã> ntc-training
cd ntc-training
uv sync
```

`uv` tạo môi trường Python riêng cho dự án, không ảnh hưởng Python của hệ thống.

## 2. Build giao diện

```bash
cd frontend
npm ci --ignore-scripts
npm run build
cd ..
```

Giao diện được build thành file tĩnh và do chính app phục vụ. App không tải script, font hay thư viện từ CDN bên ngoài.

## 3. Dựng image train

```bash
docker buildx build --builder vlm-builder --platform linux/arm64 \
  -f docker/automodel-2.Dockerfile --build-arg VLM_TAG=26.08-5 \
  -t vlm-automodel:26.08-5 --load .
```

:::caution
Image gốc của NVIDIA nặng khoảng 29,4 GB. Trên máy dùng chung, báo quản trị viên trước khi tải.
:::

## 4. Chạy app

```bash
uv run vlm-app --worker container
```

| Tuỳ chọn | Ý nghĩa |
|---|---|
| `--port` | Cổng của app, mặc định 7870 |
| `--worker container` | Chạy tác vụ thật trong container |
| `--worker fake` | Mặc định: chỉ giả lập, để thử giao diện mà không dùng GPU |

Khi khởi động, app in **một lần** đường dẫn đăng nhập dạng `http://127.0.0.1:7870/?token=…`. Mở đường dẫn này bằng trình duyệt trên cùng máy. App chỉ nghe ở `127.0.0.1`, không mở ra mạng ngoài.

<Hint title="Cài trên máy dùng chung">
Dùng `scripts/dev/app.sh` thay cho `uv run vlm-app`. Script bật chế độ `shared_dev`: chặt hơn về plugin, và cần quản trị viên duyệt khi xoá quá 20 GB dữ liệu trong 24 giờ. Xem [Quản lý dung lượng](/docs/quan-ly-dung-luong/).
</Hint>

## 5. Tự kiểm tra trước tác vụ nặng

App tự kiểm tra trước mỗi tác vụ nặng ([chi tiết](/docs/kiem-tra-truoc-khi-chay/)). Bạn cũng có thể kiểm bằng lệnh, lệnh này chỉ đọc:

```bash
uv run python scripts/cleanup/preflight.py --est-peak-gb 40 --ckpt-gb 9
```

| Mã kết thúc | Ý nghĩa |
|---|---|
| `0` | Đạt |
| `2` | Thiếu bộ nhớ hoặc swap |
| `3` | Thiếu ổ đĩa |
| `4` | GPU đang bận |

## Dữ liệu được lưu ở đâu

Mọi thứ app tạo ra nằm trong thư mục dự án:

| Thư mục | Nội dung |
|---|---|
| `.cache/` | Model và dữ liệu tải về |
| `outputs/runs/` | Mỗi lần train hoặc đánh giá một thư mục: cấu hình, nhật ký, số đo, checkpoint |
| `outputs/graph/` | Kết quả từng node của workflow và chỉ mục bộ nhớ đệm |
| `outputs/system/` | Báo cáo dung lượng, nhật ký dọn dẹp |

Thư mục cache Hugging Face chung của máy (`~/.cache/huggingface`) chỉ được đọc, app không ghi hay xoá ở đó.
